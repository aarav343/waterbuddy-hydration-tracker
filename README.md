# Water Buddy Hydration Tracker

WaterBuddy is a daily hydration tracker built with Python and Streamlit. It helps users set an age-based daily water goal, record drinks, and see their progress.

## Features

- Suggested daily goals for children, teens, adults, and seniors.
- An adjustable goal and quick or custom water entries.
- A progress bar showing today’s total, remaining amount, and percentage.
- Motivational messages at progress milestones.
- A New day button with confirmation before clearing the total.

Daily values stay in the current Streamlit session. They are not saved to an account or database.
